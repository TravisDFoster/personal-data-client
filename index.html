Personal Data Client

A single-user command-line tool for reading my own Google data.

What it is

This is a personal command-line application. It uses the Google APIs to read data from one Google Account — my own — and write it to files on my own computers. It has no other users, no server, no website that stores anything, and no sign-up.

What it does

  • Reads my Google Drive, Gmail, Calendar and Docs to organise my own notes and schedule.
  • Reads my Google Health data — sleep, resting heart rate and heart-rate variability recorded by my watch — and turns it into a small daily summary I use to plan training.
  • Saves the results as plain files in a private repository on my own machines.

Why it needs OAuth

Google requires a registered application to access an account's data, even when the developer and the user are the same person. That is the only reason this app exists as a registered OAuth client. Access is granted by me, to me.

Privacy

The app collects nothing from anyone else and shares nothing with anyone. Full detail: Privacy Policy.
