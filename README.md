# Personal Data Client

Homepage and privacy policy for a single-user OAuth application that reads my own
Google Account data (Drive, Gmail, Calendar, Google Health) onto my own machines.

These two pages exist to satisfy Google OAuth branding requirements. There is no
application code here.

- https://travisdfoster.github.io/personal-data-client/
- https://travisdfoster.github.io/personal-data-client/privacy.html
